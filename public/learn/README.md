# Learn illustrations

`illustrations.webp` retains the original four-column/two-row artwork. Only its top-right Train an opening tile is used; that approved illustration is unchanged.

`subjects.webp` contains seven distinct illustrated subjects in a four-column/two-row sheet. Row-major: repertoire strategy binder, opening doorway, endgame finish line, unused blank cell, history scroll/hourglass, encyclopedia books/globe, quiz cards, trivia buzzer. Every subject uses the same outlined painted game-art style, with different silhouettes for fast recognition. The original generated PNG remains in the workspace's generated_images folder. WebP is an encoded copy for lighter downloads.
