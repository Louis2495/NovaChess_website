# Learn illustrations

`illustrations.webp` is a four-column, two-row sheet. Row-major order: Your repertoire, Opening lessons, Endgame Lessons, Train an opening, History, Encyclopedia, Quizzes, Trivia. Pieces have traditional pedestal bases with no legs. The original generated artwork is retained in the workspace’s generated_images folder.

`refreshed.webp` supplies six revised illustrations in a three-column, two-row sheet: Opening lessons, Endgame Lessons, History, Encyclopedia, Quizzes, Trivia. These use simpler traditional piece shapes matching the variant artwork. Repertoire and Train an opening continue to use their original cells in `illustrations.webp` unchanged.
