## Material differences

Browser Stockfish uses the Lite single-threaded engine rather than the native app’s large default network. Variant bot strength is a search budget, not a calibrated competitive Elo. The new variants use their own legal-move implementation rather than claiming Fairy-Stockfish supports them.

CloudKit and Game Center are Apple-native services. Their web replacement is an optional Supabase backend, documented in [ONLINE_SETUP.md](ONLINE_SETUP.md). The code and database behavior are tested locally, but no live project, email delivery, public Realtime connection or deployment is claimed until the owner connects and deploys it.
